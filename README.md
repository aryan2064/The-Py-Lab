# The Py Lab

A monorepo of beginner-to-intermediate Python projects focused on core programming, APIs, utilities, and algorithms.  


## Featured Projects

### 1. YouTube Downloader  
An interactive terminal-based media downloader that lets users fetch YouTube videos or extract audio in different quality options using `yt-dlp`. The project emphasizes input validation, format selection, and reliable download workflows.

- **Key Features**: Video quality selection (including HD options), MP3 audio extraction, URL format validation, guided terminal prompts.  
- **Technologies**: Python, `yt-dlp`, terminal I/O.  
- **View Project**: [YouTube Downloader](https://github.com/aryan2064/The-Py-Lab/tree/main/5%20YouTube-Downloader)

### 2. Maze Solver  
A terminal maze pathfinding project that finds a route from Start (`S`) to End (`E`) using DFS or BFS strategies. The project emphasizes algorithmic thinking, grid traversal logic, and visual interpretation of computed paths.

- Key Features: Supports DFS and BFS solving modes, default and custom maze input, terminal path visualization, structured maze validation.  
- Technologies: Python, graph traversal algorithms (DFS/BFS), terminal rendering.  
- View Project: [Maze Solver](https://github.com/aryan2064/The-Py-Lab/tree/main/8%20Maze-Solver)

## Quick Start

```bash
git clone https://github.com/aryan2064/The-Py-Lab.git
cd The-Py-Lab
```

Open any project folder and run the python file.

## Notes

- Most projects are terminal-based Python scripts.
- Some projects require external APIs or tools (`OpenWeatherMap`, `Genderize.io`, `yt-dlp`).
- Dependencies and run commands are documented inside each project folder.
